## 🎨 UI/UX Design System & Visual Language

A cohesive design system ensures the entire portfolio feels **intentional, intelligent, and consistent** — from icons to illustrations to animations.  
This section defines the **core principles**, **visual assets**, and **UI styling guidelines** used throughout Hasan’s portfolio.

---

### 🌗 Design Theme

**Visual Personality:**  
> *Futuristic Minimalism with AI-inspired aesthetics.*  
The interface feels clean, calm, and technical — no visual clutter, only meaningful design.

| Element | Description |
|----------|--------------|
| **Mode** | Dark-first UI with light mode toggle (future feature) |
| **Base Background** | Deep navy black `#0f172a` or neutral charcoal `#111827` |
| **Primary Accent** | Cyan `#22d3ee` (energy, intelligence) |
| **Secondary Accent** | Emerald `#10b981` (balance, trust) |
| **Text Color** | `#ffffff` for body, `#e2e8f0` for muted text |
| **Link Hover / Active** | Gradient blend of cyan → emerald |
| **Glass Effect** | Slight glassmorphism (`rgba(255,255,255,0.04)` blur 12px) for cards and nav |

---

### 🧩 Layout System

| Component | Style |
|------------|--------|
| **Navigation Bar** | Fixed top, semi-transparent background with blur. Minimal icons + logo. |
| **Hero Section** | Full viewport height, centered layout, smooth scroll hint. |
| **Cards (Projects, Skills)** | Rounded corners `2xl`, soft shadows, glass layer, hover lift animation. |
| **Buttons** | Rounded, gradient border, hover glow. |
| **Spacing System** | Tailwind spacing scale (`p-4`, `py-8`, `mx-auto`, `gap-6`). |
| **Breakpoints** | Responsive design via Tailwind (`md`, `lg`, `xl`) — mobile-first. |

---

### 🔤 Typography

| Element | Font | Usage |
|----------|-------|--------|
| **Headings** | `Poppins` or `Satoshi` | Modern, bold, clear for titles. |
| **Body Text** | `Inter` or `DM Sans` | Legible, neutral sans-serif. |
| **Code Snippets / Tags** | `JetBrains Mono` | For a developer touch. |
| **Line Height / Spacing** | Comfortable for readability (`leading-relaxed`, `tracking-wide`). |

Use consistent type weights:
- **Bold (700)** for section headers  
- **Medium (500)** for subheadings  
- **Regular (400)** for body content  

---

### 🧠 Iconography

**Icon Pack:** [Lucide Icons](https://lucide.dev)  
All icons should:
- Be **outline-style** for minimal aesthetic  
- Use **stroke width 1.5–2px**  
- **Color inherit** from text or accent gradient  
- Maintain **consistent padding and sizing (24px / 32px)**  

**Examples:**
- 💻 `Code` → for projects  
- 🧠 `Brain` → for AI/ML  
- ⚙️ `Settings` → for tools or configuration  
- ✉️ `Mail` → for contact  

If you include custom icons, ensure they follow the same stroke and visual weight as Lucide.

### 🪄 Illustration & Graphic Style

**Illustration Type:**  
> Flat vector or semi-3D gradient illustrations — minimal, futuristic, and soft-edged.

| Asset Type | Style Guide |
|-------------|-------------|
| **Hero Illustration** | Clean geometric or gradient mesh shapes; subtle glow. |
| **Project Thumbnails** | Abstract or realistic mockups in soft shadows; framed consistently. |
| **Empty States / Banners** | Line-art style with muted cyan/emerald gradients. |

### 🎞️ Motion & Interaction Principles

**Motion Philosophy:**  
> Motion should communicate intelligence, not show off.

| Type | Example | Guideline |
|------|----------|-----------|
| **Hover** | Cards lift slightly, icons glow | Use `Framer Motion` spring animations |
| **Scroll Animations** | Fade-in or slide-up elements | Controlled via staggered delay |
| **Button Interactions** | Soft glow + scale up | Fast in, slow out easing |
| **Page Transition** | Fade crossfade between routes | Maintain fluid continuity |

Avoid:
- Overlapping motion
- Fast, jittery transitions
- Random delays  

All motion durations should fall between **0.25s – 0.6s** for smoothness.

---

### 🧭 Consistency Rules

✅ Do:
- Use **one illustration style** site-wide.  
- Keep **color accents consistent** across sections.  
- Reuse **UI components** (buttons, cards, icons).  
- Maintain **uniform padding and alignment** (grid-based).  

🚫 Don’t:
- Mix flat and 3D styles in the same page.  
- Use inconsistent icon packs (e.g., mix Font Awesome with Lucide).  
- Apply multiple animation styles simultaneously.  

---

### 🧰 Component Library Convention

| Component | Description |
|------------|--------------|
| `SectionWrapper` | Standardized container for sections with padding + max-width |
| `Card` | Used for Projects, Skills, or Testimonials |
| `Button` | Gradient + glow hover animation |
| `Tag` | Rounded chip for technologies |
| `Avatar` | Circular, glassmorphic outline |
| `Divider` | Thin gradient line used between major sections |

Each component should have:
- A defined **props interface** (for reusability)  
- **Light/dark compatibility**  
- **Accessible contrast** (AA+ compliant)
